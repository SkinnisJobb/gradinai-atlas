# Atlas documentation

This is the product documentation for Atlas: what it is, how to install and run it, and how it is
built. Pages marked *generated* are produced from the code by the named tool; edit the code, not the
page.

## Reading order

Read top to bottom the first time. Later, jump straight to the page you need.

The pages are grouped by who they are for. [Using Atlas](#using-atlas) is for everyone who works
with Atlas, people and agents alike. [Running and securing Atlas](#running-and-securing-atlas) is
for whoever installs, configures and operates an install. Each page names its group in the
`audience` field at its top (`user` or `operations-security`), and `tools/check_docs_audience.py`
checks that every page has one.
