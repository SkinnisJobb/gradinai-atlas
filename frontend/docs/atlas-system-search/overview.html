Search

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

Search is built in: keyword search in Postgres over node names and descriptions, workitem prose, acceptance criteria, results, labels, decision records and the documents a node serves.

It answers with pointers (the node, where it matched and a short snippet), never the full text. The filter for what the caller may see is applied inside the query, so a hidden node is neither counted nor shown. The route is /api/search; agents use atlas_node_search and atlas_search.
