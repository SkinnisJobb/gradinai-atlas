atlas-gateway

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

atlas-gateway is optional: an MCP gateway in front of atlas-mcp, for installs that want one MCP address for several servers and an allow-list of the tools it exposes.

It is started only with the compose profile gateway. Agents still present their own token, which the gateway passes through, so attribution and access are the same as without it.
