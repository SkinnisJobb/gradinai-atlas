atlas-mcp

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

atlas-mcp is the Model Context Protocol server agents connect to, at /mcp/. It is a translator, not a store: each tool call is forwarded to atlas-api with the calling agent's own bearer token, and the answer comes back in a fixed envelope.

Because it holds no data and no credential of its own, an agent can do through it exactly what its token allows on the API. The tools, and the order to use them in, are on the Agents page.
