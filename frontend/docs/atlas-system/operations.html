Operations

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

Install and start

In deploy/oss, copy .env.example to .env and fill it in. Run scripts/init-secrets.sh and scripts/init-certs.sh, then docker compose up -d. The atlas-migrate one-shot prepares the database before atlas-api starts.

The first owner

docker compose exec atlas-api atlas-admin user add <name> --role owner

The command prints a temporary password once, and the first sign-in forces a change. Further people are added the same way with --role member.

Upgrade

Pull the new release, rebuild and start again. atlas-migrate upgrade applies schema changes and is safe to run more than once:

docker compose exec atlas-api atlas-migrate upgrade

Health

/healthz answers without a token or a database, and is what container health checks use. /api/health needs a signed-in caller and reports the database state.

Back up

Back up the Postgres volume and deploy/oss/secrets/ together. A database restored without its peppers has no working password or token.
