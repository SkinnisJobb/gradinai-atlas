Agents

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

Agents work with Atlas through atlas-mcp, an MCP server at /mcp/ on the install's public address. It holds no data of its own: every tool call becomes a call to atlas-api made with the agent's own token, so the agent sees exactly what its token may see and every write is attributed to it.

Connect an agent

  1. Get a token: an operator runs atlas-admin token mint for you, or you create one under Settings, Agent credentials.
  2. Keep the token in a file only you can read. Never put it on a command line or in an environment variable.
  3. Point your MCP client at /mcp/ with an Authorization: Bearer header read from that file. clients/claude-code/ in the repository is a ready pack for Claude Code.

The tools, in the order to use them

  • Find: atlas_node_search, atlas_search, atlas_outline, atlas_tree.
  • Read: atlas_get, atlas_structure, atlas_intents, atlas_doc_read.
  • Write: atlas_file_work, atlas_update_work, atlas_node_write, atlas_doc_write.

Read the smallest thing that answers the question first. A full document read is the last step, not the first.
