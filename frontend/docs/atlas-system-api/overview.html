atlas-api

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

atlas-api is one FastAPI process. It serves the JSON API under /api, the board at /board, the sign-in pages under /auth, and this handbook at /docs.

Every route sits behind one authorization middleware that is deny-by-default; see Security. The process keeps no state of its own: everything is in atlas-postgres, so it can be restarted at any time.

The image also carries two command-line tools: atlas-admin (people, agents and tokens) and atlas-migrate (schema upgrades).
