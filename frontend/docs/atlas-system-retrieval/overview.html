Retrieval add-on

Skeleton page. The full handbook is written in a later pass; what is here is short and correct.

The retrieval add-on is opt-in and off by default. It adds semantic retrieval beside keyword search: it runs inside atlas-api, text is turned into embeddings by an OpenAI-compatible endpoint the install chooses, and the vectors are kept in Postgres.

No model and no embedding service ship with Atlas. It is turned on with ATLAS_RETRIEVAL and the settings beside it in .env, and the retrieval.yml compose overlay; the key is a secret file. A broken configuration never stops Atlas: search stays keyword search (see Search), and /api/health says why.
