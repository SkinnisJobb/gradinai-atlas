# MCP server (Anthropic Python SDK). PINNED EXACTLY, and it has to be.
#
# STAY ON 1.x. 2.0.0 removed `mcp.server.fastmcp` outright: the wheel's server
# subpackages are `auth`, `lowlevel` and `mcpserver`. So
# `from mcp.server.fastmcp import FastMCP` — the first import in mcp_server.py —
# is an ImportError under 2.x. A range like `mcp>=1.2.0` resolves to
# 2.x on a fresh build; two agents building this surface hit it independently.
#
# 1.30.0 since 2026-10-25 (TASK-1366, under ADR 0006; owner decision, 2026-10-25): 1.12.4,
# what the fleet first ran, is unsupported and affected by fixed advisories —
# CVE-2026-59951 (sessions never reclaimed), CVE-2026-109527 (no request body
# limit), CVE-2026-52869 (session requests served without checking the principal),
# CVE-2025-66416 (DNS rebinding). 1.30 turns two of those fixes into settings this
# service must pass explicitly — the session idle timeout and the allowed Host
# list — and app/mcp_server.py does. Bumping this is still an explicit gated task.
#
# The same latent 2.x break sits in any service that pins `mcp` with a range like that:
# its image works only until somebody rebuilds it.
mcp==1.30.0

# HTTP client for the atlas-api backend (app/client.py, app/caller_auth.py).
httpx==0.28.1
